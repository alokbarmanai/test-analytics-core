Step 4: Run Your Containerized ApplicationOnce the build completes successfully, turn off your manual background server 
if it is still running (CTRL + C in your first terminal window).
Then, spin up your new Docker container:bashdocker run -d -p 8000:8000 --name analytics-service test-analytics
Use code with caution.Note: 
The -d flag runs the container silently in the background, and -p 8000:8000 maps your Windows desktop port 8000 directly to the container's internal port 8000.

##Stop application:
1. The Command Line Way (WSL Terminal):
Run this command in your terminal to stop the container from running:
docker stop analytics-service
Step 1: Stop and Remove the Current Container
or docker stop analytics-service && docker rm analytics-service
Step 2: Run the Container with the Volume Mount Link
docker run -d -p 8000:8000 --name analytics-service -v "/mnt/d/Development Projects/source/ai projects/alokbarmanai/test-analytics-core:/app" test-analytics
Step 3: Run the Tests Inside the Container Again
docker exec -it analytics-service pytest tests/

2. The Visual Way (Docker Desktop):
Open your Docker Desktop window.
Click on the Containers tab in the left sidebar.
Find analytics-service in the list, hover over it, and click the square Square Stop Button 
(or click the Trash can icon if you want to delete the instance completely).

##Start application in Docar:
How to Bring It Back Up Again:
1. If you just stopped it: Run the start command to bring the existing container instance back online instantly:
docker start analytics-service
2. If you deleted the container container instance: Run your original launch configuration to build a fresh active instance from your image:
