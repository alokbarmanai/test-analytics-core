Step 1: Install the Parallel Execution PluginRun this installation command in your active PowerShell environment (.venv) to download the distributed test orchestration package:

Step 2: Run Tests Across Multiple CPU CoresTo execute your test suite concurrently, use the -n flag followed by the number of workers you want to spin up (or use -n auto to utilize all available processor cores automatically):
# Run using 2 dedicated workers
pytest -v -s tests/test_environment_routing.py --env=testing -n 2
